# Cubo 3D Rotacionando em C++ com OpenGL

Projeto acadêmico desenvolvido para a disciplina de computação gráfica, utilizando C++ com OpenGL e GLUT para renderização de um cubo 3D com rotação contínua em tempo real.

---

## Tecnologias Utilizadas

- C++
- OpenGL
- GLUT / FreeGLUT

---

## Funcionalidades

- Renderização de cubo 3D colorido
- Rotação contínua nos eixos X e Y
- Uso de profundidade (Depth Test)
- Projeção em perspectiva
- Atualização em tempo real com animação fluida

---

## Conceitos Aplicados

- Computação gráfica
- Transformações 3D
- Rotação de objetos
- Projeção em perspectiva
- Renderização em tempo real
- Animação
- Controle de profundidade (Depth Test)
